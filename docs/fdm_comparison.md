# FDM and Radial Comparison

## Scope

The paper states the grid sizes, time steps, boundary conditions, radial
equations, and error formula, but the original FDM source and its exact stencil
are not present in this repository. The implementation here is therefore a
documented reproduction using a standard conservative central-flux stencil. It
should be used to reproduce the comparison workflow and trends; numerical
values should not be claimed to be generated by the unreleased original FDM
program.

## Three-dimensional FDM

The cube is divided into `N^3` cell-centered control volumes with `dx=L/N`.
On an internal face, the tumor-cell flux is

```text
q = d1 (rho_R-rho_L)/dx
    - gamma (rho_R+rho_L)/2 (f_R-f_L)/dx.
```

The two neighboring cells receive opposite flux contributions. Boundary-face
fluxes are zero, implementing

```text
d1 partial_n rho - gamma rho partial_n f = 0.
```

The MDE diffusion flux is treated in the same way with homogeneous Neumann
data. Time integration is explicit and follows the SIPF splitting order:

1. update `rho_(n+1)` from `rho_n,f_n`;
2. update `f_(n+1)` from `f_n,m_n`;
3. update `m_(n+1)` from `m_n,rho_(n+1)`.

The configuration validator checks the three-dimensional explicit diffusion
condition `6 max(d1,d2) dt/dx^2 <= 1`.

## Radial reference

The spherical PDE is written in conservative form:

```text
rho_t = r^-2 partial_r [
    r^2 (d1 partial_r rho - gamma rho partial_r f)
]

m_t = d2 r^-2 partial_r(r^2 partial_r m) - beta m + alpha rho.
```

The radial cells are spherical shells. Face areas are proportional to `r^2`
and shell volumes to `(r_right^3-r_left^3)/3`, so the origin requires no
division by a point value `r=0`. Haptotaxis and ECM degradation are explicit;
the diffusion operators for `rho` and `m` are implicit tridiagonal solves.
This IMEX choice is stable for the paper's `dr=1/801, dt=0.001`.

The reference domain radius is one. Only `r<=L/2` is used in cube comparisons,
which avoids incomplete spherical shells near the corners of the cube.

## Radial averaging

FDM values live at cell centers:

```text
x_i = -L/2 + (i+1/2)L/N.
```

SIPF fields live at FFT nodes:

```text
x_i = -L/2 + iL/H.
```

The converter uses these conventions separately. Values are grouped by radius
and averaged in each nonempty shell. Every grid in a sweep uses the same bin
edges (`profile_bins=20` in the paper-scale configuration), so the reported
convergence rates compare the same radial intervals. The MDE error is the
unweighted bin error stated in the paper:

```text
||m_method-m_reference||_2 / ||m_reference||_2.
```

The reference solution is interpolated to the actual mean radius of each
nonempty three-dimensional shell.

## Commands

Quick workflow test:

```bash
cancer-fdm-comparison --config configs/fdm_comparison_quick.json
```

Full paper grid sweep, radial reference, and SIPF run:

```bash
cancer-fdm-comparison --config configs/fdm_comparison.json
```

Individual solvers:

```bash
cancer-fdm --config configs/fdm_paper_101.json
cancer-radial --config configs/radial_reference.json
```

Convert an existing snapshot:

```bash
cancer-radialize runs/fdm_101/fdm_snapshot_000400.npz \
  --kind fdm --output runs/fdm_101/m_radial.npz

cancer-radialize runs/paper_radial/snapshot_000400.npz \
  --kind sipf --output runs/paper_radial/radial.npz
```

The full comparison writes `fdm_grid_sweep.csv`,
`comparison_summary.json`, per-grid radial profiles, and
`final_m_radial_profiles.png`.
